# NOVA Ultimate 21.4.4 — Guardian consent-first security assessment

This patch adds a real but deliberately limited first milestone: passive HTTP security-header assessment of a public server, a downloadable JSON report, server-side consent/authorisation checks, rate limiting, audit events and a phone security self-checklist. It preserves the existing NOVA chat, camera, voice and role architecture.

No server repairs or device malware scans are claimed in this release. Those require the later native companion and consent-gated remediation stages documented in `NOVA-GUARDIAN-21.4.4.md`.

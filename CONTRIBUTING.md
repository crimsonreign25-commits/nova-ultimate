# Contributing to NOVA Ultimate

NOVA Ultimate is being developed openly. Contributions should preserve the project's guest-first design and safety boundaries.

## Before submitting changes

1. Run `npm run test:syntax`.
2. Run `npm test`.
3. Do not commit `.env`, API keys, credentials, generated runtime data, or `node_modules`.
4. Keep builder operations sandboxed and bounded.
5. Add or update tests for changes to autonomous execution, recovery, builder, or workspace safety.

## Pull requests

Describe the problem, the change, the tests performed, and any new security or operational considerations.
